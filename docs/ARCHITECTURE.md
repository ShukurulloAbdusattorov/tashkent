# Amir Temur Square — Unity 6.3 HDRP open-world slice

## Goal
Realistic, RDR-style third-person walking experience of Amir Temur Square, Tashkent, built from real OpenStreetMap geometry.
Target: Windows x64 player, HDRP High Fidelity. Everything is generated by Editor scripts run in batchmode; no manual editor work.

## Project
- Unity project: `D:\Tashkent city\AmirTemurSquare` (HDRP 17, Input System 1.12, Cinemachine 3.x, Unity 6000.3.9f1)
- Editor exe: `D:\Unity downloads\6000.3.9f1\Editor\Unity.exe`
- Only ONE Unity instance can open the project at a time. Agents must NOT launch Unity; the orchestrator runs compile/generation passes.
- Package sources for API reference: `AmirTemurSquare\Library\PackageCache\com.unity.render-pipelines.high-definition@*`, `com.unity.cinemachine@*`, `com.unity.inputsystem@*`, `com.unity.render-pipelines.core@*`.
  Verify every non-trivial API you use by grepping those folders. Unity 6.3 APIs: `Object.FindFirstObjectByType`, `FindObjectsByType`, no `FindObjectOfType`.

## Data

  Unity mapping: json `[x, z]` -> `new Vector3(x, 0, z)` (x east, z north, y up). Ground plane y = 0. Polygons `outer` are CCW in x/z (map view); `inners` CW.
  Keys: buildings[{id,name,type,height,levels,min_height,roof,colour,material,outer,inners,part?}], roads[{id,cls,name,width,lanes,oneway,surface,pts,bridge,tunnel,layer}],
  paths[{id,cls(footway|steps|pedestrian|path|cycleway),width,surface,pts,layer,tunnel}], areas[{id,kind(grass|wood|parking|fountain|water|plaza|pitch),name,outer,inners,layer}],
  trees[[x,z,leaf_type,genus]], benches[{x,z,yaw,backrest}], bins[{x,z}], lamps[{x,z}], kerbs/fences/hedges/walls[{id,pts,height}],
  pois[{kind,x,z,name,tags}], crossings[[x,z]], signals[[x,z]], stops[{x,z,name}], landmarks{hotel_uzbekistan,forum_palace,timurid_museum,chimes,law_university,navoi_theater,central_bank,hampton:{id,center,height}, monument:{center}}
- Raw assets: `D:\Tashkent city\data\raw\` -> polyhaven_models/<name>/<name>.fbx + textures/, hdri/*.hdr, ambientcg/*.zip, Standard-Assets-Characters-master.zip
- Processed assets are placed by the orchestrator under `Assets/AmirTemur/Art/Textures/<Set>/` with files: `<Set>_BaseColor.png|jpg`, `<Set>_Normal.png`, `<Set>_Mask.png` (HDRP mask: R metallic, G AO, B detail, A smoothness), optional `<Set>_Height.png`.
  Poly Haven models under `Assets/AmirTemur/Art/Models/<name>/<name>.fbx` + `textures/` (same naming after processing).

## Code layout (namespace `AmirTemur`)
- `Assets/AmirTemur/Runtime/` — runtime MonoBehaviours (player, camera helpers, day/night, fountain FX, LOD/culling helpers).
- `Assets/AmirTemur/Editor/` — editor-only generators. Entry point `AmirTemur.Editor.BuildAll.Run()` (orchestrator writes this) calls in order:
  1. `AssetImportSetup.Run()`         — importer settings, materials for textures/models, prefabs (Agent: assets+scene)
  2. `SceneSetup.CreateScene()`       — new scene, HDRP volume/sky/fog/post, sun, quality (Agent: assets+scene)
  3. `CityBuilder.Build(root)`        — OSM geometry + prop scatter (Agent: city)
  4. `Landmarks.Build(root)`          — bespoke landmark models (Agent: landmarks)
  5. `PlayerSetup.Create(spawn)`      — character, animator, Cinemachine camera, input (Agent: character)
  6. Save scene `Assets/AmirTemur/Scenes/AmirTemurSquare.unity`, add to build settings.
- Shared helpers the orchestrator provides in `Assets/AmirTemur/Editor/Shared/`:
  - `MaterialLibrary.Get(string key)` -> Material (HDRP/Lit). Keys: asphalt, asphalt_worn, sidewalk_concrete, paving_plaza, paving_granite, paving_small, marble_white, marble_dark,
    granite_red, grass, grass_dry, soil, brick, facade_office, facade_glass, facade_soviet, concrete_smooth, concrete_rough, plaster_white, metal_dark, metal_painted, roof_tiles, tiles_blue, water, rock, wood, kerb, travertine, road_marking_white.
    Unknown keys return a neutral grey HDRP/Lit material (never null). Materials created lazily as assets in `Assets/AmirTemur/Art/Materials/`.
  - `MeshUtil` : `Triangulate(List<Vector2> outer, List<List<Vector2>> holes)` ear-clipping (returns indices), `ExtrudePolygon`, `Ribbon(List<Vector3> centreline, float width)`, `Combine`, `SaveMeshAsset(mesh, path)`.
  - `PrefabLibrary.Get(string key)` -> GameObject prefab or null. Keys: tree_jacaranda, tree_small, tree_island, shrub_02, shrub_03, shrub_04, fir_sapling, lamp_01, lamp_02, bench_wood, bench_modern, trash_can, hydrant, manhole, horse_statue, planter, car_covered.
- Static meshes generated at edit-time must be saved as assets (`AssetDatabase.CreateAsset`) under `Assets/AmirTemur/Generated/` so the scene serialises, and marked static (`GameObjectUtility.SetStaticEditorFlags`) for GI/occlusion/batching.
- Large procedural meshes: split into chunks (< 64k verts unless using UInt32 index format; prefer chunking ~100 m for culling).
- Every renderer: cast shadows on, proper UVs in metres (1 unit = 1 m) so tiled materials look right (materials use tiling ~ 1/size).
- Colliders: MeshCollider on ground/buildings/kerbs; player uses CharacterController.

## Rendering conventions
- HDRP Lit materials; use `HDMaterial.SetXXX` helpers / `HDMaterial.ValidateMaterial` after property changes.
- Sun: Directional Light ~ 100k lux (physical units), sky: PhysicallyBasedSky, Fog volumetric, exposure automatic, Bloom, Tonemapping ACES, SSAO/SSGI/SSR on, contact shadows, shadows 4 cascades.
- Time of day: late afternoon default (sun elevation ~25°, warm), optional `DayNightCycle` runtime component.
